台账后台管理

文档名称批量导入

按模板导入：先「下载模板」得到 CSV，用 Excel 填写每行的「台账名称」后保存为 CSV，再「选择 CSV 上传导入」。
格式：柜号,层号,序号,台账名称，层号 1=第 1 层（最上层），序号 1=每个柜每层从左到右第 1 个。

柜体配置（数量 + 单开/对开组合）

在这里设置柜子数量，并为每个柜子选择「对开 / 单开」。保存后 APK 三维场景、目录管理、文件管理都会按新配置刷新。新增柜子默认为空（备用），删除柜子会同时删除其下已上传的文件。

用户角色操作

台账备份 / 还原

备份会打包：台账目录、已上传文件、用户账号。还原后按备份内容直接覆盖当前数据。
