目录管理

点击或拖拽文件到此处上传

支持图片、PDF、Word、Excel、PPT、文本等格式

柜体配置

设置柜子数量，为每个柜子选择「对开 / 单开」及每层档案盒颜色。保存后 APP 三维场景会按新配置刷新。新增柜子默认为空（备用），删除柜子会同时删除其下已上传的文件。

文档名称批量导入

按模板导入：先「下载模板」得到 CSV，用 Excel 填写每行的「文档编号」与「台账名称」后保存为 CSV，再「选择 CSV 上传导入」；也可「导出 CSV」保存当前目录。
格式：柜号,层号,序号,文档编号,台账名称，层号 1=第 1 层（最上层），序号 1=每个柜每层从左到右第 1 个，编号留空时三维场景按序号显示。兼容旧版四列 柜号,层号,序号,台账名称 模板。

用户角色操作

台账备份 / 还原

备份会打包：台账目录、已上传文件、用户账号。还原后按备份内容直接覆盖当前数据。

操作日志（最近 300 条）

记录登录、文件上传/预览/下载、备份还原、用户管理等关键操作，用于发现内网资料异常访问。
