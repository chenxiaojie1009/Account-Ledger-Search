台账查找系统 - Windows 后端部署说明
========================================

架构说明
- 前端 = Android APK：只做查看（三维柜子、动画、台账位置、台账文件内容）。
- 后台管理 = 网页（浏览器打开 http://<电脑IP>:10600/admin）：
  登录后可修改台账名称/数量、上传删除文件、管理用户权限。
- 后端端口：10600（同时提供数据接口和后台管理网页）。
- 浏览器输入 http://IP:10600 会自动跳转到后台管理网页 /admin。

一、构建后端 EXE（在你的电脑上做一次）
1. 进入 backend 目录。
2. 双击 build_backend.bat（自动 pip 安装依赖并运行 pyinstaller）。
3. 生成文件：backend\dist\TaizhangBackend.exe

二、部署到目标 Windows 电脑
1. 将 TaizhangBackend.exe 和本 deploy 文件夹一起拷贝到目标电脑（免安装 Python/Node）。
2. 双击「启动.vbs」（推荐，静默启动，自动打开后台管理网页 http://127.0.0.1:10600/admin）
   或「启动.bat」。
3. 后台管理登录：admin / 123456（可新增 editor / viewer 用户）。
4. 备份 / 还原：后台「备份」页可一键下载备份 zip（台账目录+文件+用户），导入 zip 即可还原。

三、平板端（Android APK，仅查看）
1. 安装 dist 目录的 APK（台账查找-v1.1-debug.apk）。
2. 平板与电脑连同一局域网。
3. 电脑 ipconfig 查看 IP（例如 192.168.1.5）。
4. 打开 APK，登录界面「后端地址」填 http://192.168.1.5:10600，再登录。
5. App 自动拉取台账名称/文件，显示三维柜子、台账位置与内容（只读）。

四、数据
- 数据库：data\app.db（首次启动自动生成，位于 Exe 同级 data 目录）
- 上传文件：data\uploads\

五、注意
- 防火墙需放行 10600 端口。
- APK 内没有后台管理，所有增删改都在网页 http://<IP>:10600/admin 完成。
